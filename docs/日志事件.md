# 日志事件

登录服通过 log-sdk 上报事件日志，管理后台「日志中心」按项目查询。链路、字段规则见 log-sdk `README.md`。

- 初始化：`config/LogConfig`，App Key 取 `app.key`，服务器标识取 `server.node-id`（`login-1`），目录取 `log.dir`（默认 `logs/event`，相对工作目录）。
- 本机 Vector 的 `LOG_DIR` 要包含这个目录。
- `data` 字段只增不改不删。

| 事件 | actor | data | 时机 |
| --- | --- | --- | --- |
| `anchor_login` | 登录服账号 ID（`login_user.id`） | `platform`（`douyin` / `local`）、`roomId`（字符串，本地登录为空）、`zoneId`、`ip`、`clientVersion`、`resourceVersion` | 登录成功，票据已生成 |
| `anchor_login_fail` | 空 | `type`（`business` / `system`）、`reason`、`ip`、`platform`、`account`、`clientVersion`、`resourceVersion` | 登录失败（版本过低、服务器维护中、抖音接口失败等） |

游戏服的 `anchor_login` 带 `userId`，与这里的 actor 对应；`roomId` 与回调服事件里的 `roomId` 对应。
